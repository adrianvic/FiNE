# FiNE
A fork of AFFiNE that removes telemetry, forced AI features and other QoL additions. Because AFFiNE can be FiNE without that.

## Setup
### Docker
Like you would with AFFiNE, but use the container from this repo.

### Local
```
yarn workspace @affine/templates build
yarn dev -p @affine/web
```

## Features
 - [X] No telemety
 - [ ] Option to disable AI features
